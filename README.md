# Dashboards Skadi

Este repositório prepara as bases que alimentam os dashboards do Skadi.

## Dashboards disponíveis

- **Chamados:** acompanha volume, situação, categoria, responsável, evolução diária e tempo de resolução dos chamados de suporte.
- **Superadmin:** apresenta a distribuição de usuários por nível de acesso, os indicadores de chamados e a última execução bem-sucedida do RPA.

## Estrutura

- `site/`: notebooks e pipeline das bases dos dashboards de Chamados e Superadmin.
- `app/`: reservado para dashboards adicionais da aplicação quando seus KPIs forem definidos.
- `docs/`: definição de métricas e fontes de dados.
